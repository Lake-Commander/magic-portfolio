## Overview

This project explores transactional retail data to uncover operational
and customer experience trends across branches and product lines.

## Key Features

-   Revenue and gross income trend analysis.
-   Payment method behavior insights.
-   Branch performance comparison.
-   Visual analytics and reporting.

## Technologies Used

-   Python (pandas, matplotlib, seaborn)

## Outcome

Provides retail decision-makers with data-driven operational and
marketing insights.
