## Overview

Built to optimize delivery operations, this project predicts late shipments using structured operational features and presents insights via an interactive dashboard.

## Key Features

- **Delay Classification**: Predict whether a shipment will arrive late.
- **Derived Logistics Features**: Shipping delay days, order weekday/weekend behavior, and operational flags.
- **Dashboard + EDA**: Visual inspection of delay drivers and operational bottlenecks.

## Technologies Used

- **Python (pandas, scikit-learn)**
- **Streamlit**
- **Visualization**: matplotlib

## Challenges and Learnings

Shipping datasets often contain multiple “leakage” fields (e.g., post-delivery indicators). The project required careful feature selection to avoid cheating the model.

## Outcome

A deployable analytics tool that supports operational decision-making and highlights drivers of delivery delays.
