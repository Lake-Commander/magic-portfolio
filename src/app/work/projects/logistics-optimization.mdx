## Overview

Built to optimize delivery operations, this project predicts late
shipments using structured operational features and presents results via
an interactive dashboard.

## Key Features

-   Delivery delay classification modeling.
-   Feature engineering from date and shipping variables.
-   Integrated EDA visualizations within the app.

## Technologies Used

-   Python
-   scikit-learn
-   Streamlit

## Challenges and Learnings

Handling multiple shipping-related derived features required careful
data transformation logic.

## Outcome

Provides operational insight for logistics performance improvement.
