## Overview

This project delivers a full regression-based machine learning pipeline
for predicting customer insurance premiums. It integrates preprocessing,
feature engineering, model evaluation, and deployment in a
production-ready Streamlit interface.

## Key Features

-   Full ML pipeline from raw data to deployment.
-   Multiple regression models evaluated (Linear, Ridge, Lasso, Random
    Forest).
-   Performance evaluation using MSE and R² metrics.
-   Live interactive prediction interface.

## Technologies Used

-   Python (pandas, scikit-learn)
-   Streamlit
-   Model Serialization (joblib)

## Challenges and Learnings

Ensuring consistent feature scaling between training and deployment
required careful pipeline structuring and validation checks.

## Outcome

The system provides reliable premium estimates and demonstrates
production-level ML deployment skills.
