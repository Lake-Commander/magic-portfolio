## Overview

This project delivers a full regression-based machine learning pipeline for predicting customer insurance premiums. It integrates preprocessing, feature engineering, model evaluation, and deployment in a production-ready Streamlit interface.

## Key Features

- **End-to-End Pipeline**: Data cleaning → feature engineering → training → evaluation → deployment.
- **Multi-Model Benchmarking**: Linear Regression, Ridge, Lasso, and Random Forest compared with consistent metrics.
- **Deployment Consistency**: Input scaling and feature ordering aligned with training to prevent prediction drift.
- **User-Friendly UI**: Streamlit form inputs and readable prediction outputs.

## Technologies Used

- **Python (pandas, NumPy, scikit-learn)**
- **Streamlit**
- **Model persistence**: joblib

## Challenges and Learnings

A major deployment risk was mismatch between training-time feature transformations and inference-time inputs. The solution was a consistent preprocessing approach and strict feature ordering.

## Outcome

A deployable ML application that produces premium estimates and demonstrates end-to-end model delivery in a product-ready format.
