## Overview

This project analyzes textual and metadata patterns to classify news as fake or real. It combines traditional NLP techniques with richer engineered signals (sentiment, term frequency, publication patterns) to improve real-world performance.

## Key Features

- **Text Feature Engineering**: Word counts, TF-based features, and sentiment signals.
- **Metadata Features**: Domain extraction and time-based patterns for publisher behavior.
- **Modeling**: Baselines plus stronger models for classification.
- **Interpretability Focus**: Features designed to be explainable to non-technical stakeholders.

## Technologies Used

- **Python (pandas, scikit-learn)**
- **NLP feature engineering**
- **Streamlit (optional UI layer if enabled in repo)**

## Challenges and Learnings

The biggest challenge was building signals that generalize across publishers instead of overfitting to a few sources. The solution was careful feature design and validation strategy.

## Outcome

A practical misinformation classifier that showcases robust NLP feature engineering and deployable ML workflow design.
