## Overview

This project analyzes textual and metadata patterns to classify news as
fake or real. It combines traditional NLP techniques with LLM-derived
features to enhance predictive accuracy.

## Key Features

-   Sentiment analysis and term frequency extraction.
-   Metadata-based feature engineering (domain, publication timing).
-   Logistic Regression and Random Forest models.
-   Deployable Streamlit interface.

## Technologies Used

-   Python (scikit-learn, NLP libraries)
-   Streamlit

## Challenges and Learnings

Balancing model interpretability with performance required careful
feature selection and validation.

## Outcome

The solution demonstrates practical NLP modeling combined with modern AI
feature augmentation.
