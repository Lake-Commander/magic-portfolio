## Overview

This project analyzes multi-year inventory and sales data using
structured SQL queries to extract revenue trends, customer segmentation
insights, and shipping performance evaluations.

## Key Features

-   Revenue breakdown by category and region.
-   Customer and product profitability insights.
-   Shipping cost alignment analysis.
-   Structured SQL query documentation.

## Technologies Used

-   SQL Server / SSMS

## Outcome

Demonstrates business intelligence reasoning and structured query
optimization for decision support systems.
