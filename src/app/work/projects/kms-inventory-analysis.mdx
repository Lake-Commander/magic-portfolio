## Overview

This project is a structured SQL business intelligence case study analyzing inventory and sales performance over multiple years. The focus is on answering operational questions with clean queries and actionable recommendations.

## Key Features

- **Revenue Analysis**: Category, region, and customer-level revenue breakdown.
- **Profitability Views**: Identify high/low margin segments and products.
- **Shipping Cost Review**: Evaluate efficiency and alignment with priority classes.

## Technologies Used

- **SQL Server / SSMS**
- **Relational modeling and query optimization**

## Challenges and Learnings

Turning “messy business questions” into clean SQL outputs required careful assumptions, consistent filters, and validation checks.

## Outcome

A BI-focused project demonstrating strong SQL reasoning, analytical storytelling, and operational recommendations.
