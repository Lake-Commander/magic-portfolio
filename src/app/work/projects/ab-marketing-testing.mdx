## Overview

This project evaluates the effectiveness of digital marketing strategies
using structured A/B testing methodologies. It compares conversion
performance between treatment and control groups using statistical
significance testing.

## Key Features

-   Hypothesis formulation and statistical validation.
-   Chi-square test for conversion comparison.
-   Business-focused interpretation of statistical outcomes.
-   Interactive Streamlit dashboard.

## Technologies Used

-   Python (SciPy, pandas)
-   Streamlit

## Outcome

Provides actionable insights into marketing performance optimization
using rigorous statistical analysis.
