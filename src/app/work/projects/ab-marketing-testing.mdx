## Overview

This project evaluates campaign effectiveness using A/B testing. It compares treatment vs control conversion outcomes using hypothesis testing and business-first interpretation.

## Key Features

- **Experiment Design**: Clear hypotheses, treatment/control framing, and outcome definitions.
- **Statistical Testing**: Significance testing for conversion differences.
- **Decision Support**: Results translated into business actions (rollout vs iterate).

## Technologies Used

- **Python (pandas, SciPy)**
- **Streamlit (for reporting UI)**

## Challenges and Learnings

The main challenge was communicating statistical results without “stats-speak.” The reporting focuses on effect, confidence, and what action to take next.

## Outcome

A strong portfolio case study showing experimentation fundamentals, statistical reasoning, and decision-centric reporting.
