## Overview

This project predicts burnout risk using job characteristics, fatigue scores, and workplace settings. It combines EDA with regression modeling to support HR and wellbeing decisions.

## Key Features

- **Burnout Risk Modeling**: Regression approach predicting continuous burn rate.
- **Multi-Model Training**: Linear, Ridge, Lasso, Random Forest evaluated.
- **EDA Visuals**: Correlation and bivariate analysis to understand drivers.

## Technologies Used

- **Python (pandas, scikit-learn)**
- **Streamlit**
- **Visualization**: matplotlib

## Challenges and Learnings

The biggest lesson was managing mixed data types and missing values without distorting the target distribution.

## Outcome

A deployable burnout prediction tool that demonstrates applied workforce analytics and model deployment workflow.
