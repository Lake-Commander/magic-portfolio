## Overview

This project analyzes global COVID-19 datasets to track infection rates, deaths, and vaccination trends through visual exploration and dashboard-style reporting.

## Key Features

- **Time-Series Trends**: Daily and cumulative case/death patterns.
- **Country Comparisons**: Identify hotspots and relative progression over time.
- **Visualization-First Reporting**: Clear charts suitable for dashboards and briefs.

## Technologies Used

- **Python (pandas)**
- **Visualization**: matplotlib
- **Streamlit (optional dashboard layer if enabled in repo)**

## Challenges and Learnings

Public health datasets vary by country and reporting cadence. Normalizing and comparing trends required careful handling of missingness and reporting artifacts.

## Outcome

A clear, dashboard-friendly COVID trend analysis suitable for public reporting and comparative insight.
