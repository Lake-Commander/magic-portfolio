## Overview

This project analyzes global COVID-19 datasets to track infection rates,
deaths, and vaccination trends through visual exploration and
interactive dashboarding.

## Key Features

-   Country-level case and death comparisons.
-   Time-series trend visualization.
-   Streamlit dashboard integration.

## Technologies Used

-   Python (pandas, matplotlib)
-   Streamlit

## Outcome

Provides clear visualization of global pandemic trends for comparative
analysis and reporting.
