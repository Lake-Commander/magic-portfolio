## Overview

This project evaluates Amazon product pricing and review data to answer structured business questions using Excel-based modeling and dashboarding.

## Key Features

- **Power Query Cleaning**: Structured transformation steps for reliable analysis.
- **Pivot Dashboards**: Quick insight panels for discounts, categories, and rating behavior.
- **Revenue Potential**: Simple, explainable metric estimation for opportunity ranking.

## Technologies Used

- **Microsoft Excel**
- **Power Query**
- **Pivot Tables**

## Challenges and Learnings

The key challenge was creating a repeatable transformation pipeline in Excel so insights remain consistent even when data updates.

## Outcome

A practical analytics project showing strong spreadsheet BI skills and decision-focused reporting.
